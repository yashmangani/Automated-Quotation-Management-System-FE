# Automated-Quotation-Management-System-FE

## Quotation Generator : Automated Quotation Management System

A modern, responsive React-based web application for automated quotation generation, item and product catalog management, and user administration.

### Features
- 📄 **Automated Quotation Generation**: Fast creation, customization, and export to PDF.
- 📦 **Item & Catalog Management**: Add, update, view, and organize products and tiles.
- 👥 **User Management & Authentication**: Multi-role support (`admin` & `sales`).
- ⚡ **Real-time Backend Integration**: Powered by Express & MongoDB.

### Getting Started

#### 1. Clone Repository
```bash
git clone https://github.com/yashmangani/Automated-Quotation-Management-System-FE.git
cd Automated-Quotation-Management-System-FE
```

#### 2. Install Dependencies
```bash
npm install
```

#### 3. Environment Setup
Configure your API URL in `.env`:
```env
REACT_APP_API_BASE_URL=https://back-end-07e6.onrender.com
```

#### 4. Run Application
```bash
npm start
```
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

#### 5. Build for Production
```bash
npm run build
```
Creates an optimized production bundle in the `build/` folder.
